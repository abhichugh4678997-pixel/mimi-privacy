# Privacy Policy - Mimi YT Automation

Last updated: October 2026

Mimi YT Automation is a private tool used by one person to publish the owner's own videos to the owner's own YouTube channel (Little MiMi / little.m.i.m.i).

## Data we access
The tool uses the YouTube Data API only for the owner's own Google account, to upload videos, set titles and descriptions, and add videos to playlists. It runs with the owner's authorization.

## Data we collect and share
This tool does not collect personal data from other people. It does not sell, share, or transfer Google user data to anyone. Data stays inside the owner's own accounts.

## Google API Services disclosure
The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
